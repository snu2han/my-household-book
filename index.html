Google Drive 연결 전 · 로컬 데이터만 표시

처음 연결하면 Drive에서 기존 파일을 찾아 불러옵니다. 없으면 빈 가계부 상태로 시작하며, Drive에 저장을 누르면 전용 폴더와 파일을 만듭니다. 기존 데이터는 아래 JSON 파일 가져오기를 이용하세요.

수정 후 약 2초 뒤 자동 저장합니다. 여러 기기에서 수정한 경우 충돌 감지 시 덮어쓰지 않습니다. 브라우저가 닫히기 전에 동기화 상태를 확인하세요.

백업 · 기존 엑셀 데이터 가져오기

기존 엑셀에서 변환한 데이터는 별도로 제공되는 비공개 JSON 파일을 가져와야 합니다. 이 파일은 공개 GitHub 저장소에 업로드하지 마세요.
